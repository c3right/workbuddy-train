# WorkBuddy L1 通关卡

第一次培训结束时，不要求你“会很多功能”。只检查下面这些最基本但重要的能力。

## L1 PASS

- [ ] 我知道 WorkBuddy 可以围绕一个真实工作目录持续做事，而不只是聊天。
- [ ] 我会选择一个项目目录，并先让 Agent 看懂已有资料。
- [ ] 我知道什么时候应该先“只读理解”，而不是马上让 Agent 改文件。
- [ ] 我能引用单个文件作为输入。
- [ ] 我能让 Agent 读取一整个文件夹并跨文件综合信息。
- [ ] 我能说清楚一次任务的 **做什么 / 有什么 / 怎么样**。
- [ ] 我知道大任务应该拆成几步，而不是第一句话就要求“全部做完”。
- [ ] 我会给 Agent 一个参考样例，而不是只说“专业一点”。
- [ ] 我能让 WorkBuddy 真正生成一个工作文件。
- [ ] 我会打开结果，检查事实、逻辑、遗漏和证据边界。
- [ ] 当结果不满意时，我会指出具体问题并继续修改，而不是一轮定生死。
- [ ] 我知道重要成果要保留 `v1 / v2`，避免覆盖后无法回退。
- [ ] 我知道同一任务继续原 Task；明显换了一件事，考虑新建 Task。
- [ ] 我知道 AI 输出不是最终责任答案，最终验收由人承担。

## 第一次培训不要求

- Skill 制作
- Connector 配置
- Automation
- API
- Git
- CLI
- subagent
- Python / npm 环境配置
- token / MCP 等底层技术概念

> 通过标准：上面的 L1 PASS 项目中，核心操作与心智模型能够独立完成即可。不是考试，也不要求提示词逐字一致。
