# Lab Reset

第一次培训不向学员讲 Git，也不要求他们理解版本控制工具。

如果项目目录被改乱，讲师采用最简单的恢复方式。仓库内干净源目录为 `training/lab/新岚汽车渠道研究项目/`：

1. 保留学员当前目录用于复盘；
2. 从一份干净的 `新岚汽车渠道研究项目` 原始副本重新复制一份；
3. 新副本中 `03-output/` 只保留原始 `README.md`；
4. 重新在 WorkBuddy 中选择这份干净目录继续。

正式分发前，建议讲师自己保留：

- `新岚汽车渠道研究项目-clean/`：只读母版；
- `新岚汽车渠道研究项目-demo/`：讲师演示使用；
- 学员每人自己的项目副本。

不要通过“覆盖原始输入文件再改回来”的方式恢复现场。

Phase 4 已验证这种“干净母版 → 复制工作副本”的恢复方式足够简单，不需要在第一次培训引入 Git。
