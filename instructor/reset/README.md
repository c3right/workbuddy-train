# Lab Reset

第一次培训不向学员讲 Git，也不要求他们理解版本控制工具。

如果练习目录被改乱，讲师采用最简单的恢复方式：

1. 保留学员当前目录用于复盘；
2. 从一份干净的 `WorkBuddy-L1-Lab` 原始副本重新复制一份；
3. 新副本中 `03-output/` 只保留原始 `README.md`；
4. 重新在 WorkBuddy 中选择这份干净目录继续。

正式分发前，建议讲师自己保留：

- `WorkBuddy-L1-Lab-clean/`：只读母版；
- `WorkBuddy-L1-Lab-demo/`：讲师演示使用；
- 学员每人自己的练习副本。

不要通过“覆盖原始输入文件再改回来”的方式恢复现场。

Phase 4 Dry Run 时，将进一步验证是否需要提供可直接下载的干净 ZIP。
